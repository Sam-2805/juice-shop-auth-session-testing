# OWASP Juice Shop Authentication & Session Testing

## Overview
This repository contains detailed vulnerability assessment and penetration testing reports focused on **authentication** and **session management** weaknesses in the OWASP Juice Shop web application.

The tests explore common attack vectors such as weak credentials, SQL injection, brute force login, session fixation, token reuse, and improper logout behavior. These findings highlight critical security gaps and help improve overall application security.

## Tools Used
- Burp Suite  
- Chrome DevTools  

## Contents
- Comprehensive markdown vulnerability report  
- Supporting screenshots documenting each test step  
- Notes on impact and mitigation suggestions  

## Usage
Feel free to review the reports to understand authentication and session-related security flaws commonly found in web applications. 

## Disclaimer
This testing was performed in a controlled environment on OWASP Juice Shop (a purposely vulnerable app). Do **not** attempt these tests on unauthorized systems.
